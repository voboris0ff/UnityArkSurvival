# Roadmap

Статусы: `[ ]` — ожидает выполнения, `[x]` — выполнено, `[!]` — ждёт ответа пользователя в `manual-queue.md`.
Одна задача = одна сессия OpenCode. Не брать следующую задачу в рамках той же сессии.
Заблокированные (`[!]`) задачи не останавливают работу: агент берёт следующую `[ ]`.

- [x] **DINO-001** Изучить текущую структуру AI/Data и определить минимальный контракт CreatureController. Не менять код; зафиксировать найденные зависимости и план файлов в progress.md.
- [x] **DINO-002** Создать `CreatureConfig` ScriptableObject-класс с начальными параметрами навигации, восприятия, памяти и атаки. Не создавать/редактировать `.asset`.
- [x] **DINO-003** Создать `CreatureNavigator` на базе NavMeshAgent: кэширование компонента, установка/сброс цели, остановка, скорость, проверка доступности пути и безопасные проверки состояния агента.
- [x] **DINO-004** Создать `CreatureController` как точку композиции: ссылки на config, NavMeshAgent и компоненты существа; минимальная валидация ссылок и понятные сообщения об ошибках.
- [x] **DINO-005** Добавить минимальное состояние Idle и `CreatureStateMachine` (если это оправдано найденной архитектурой). Не переносить FSM игрока механически; не создавать универсальный фреймворк.
- [x] **DINO-006** Добавить возможность задать исходную точку существа и команду вернуться к ней. Пока без патруля и восприятия. — Выполнено и проверено в Play Mode (клавиша `R` в `CreatureDebugInput`); исправлен `CreatureNavigator.IsPathActive` (порядок `pathPending`/`hasPath`).
- [x] **DINO-007** Добавить простую настройку Animator-параметров движения существа, только если известны фактические имена параметров/анимаций. Иначе создать ручную задачу и не выдумывать их. — Выполнено: `CreatureAnimator` публикует `Speed` (float, м/с); клипы `walk`/`run` у Raptor есть (ответ пользователя), имя параметра и слои блендтри настраиваются пользователем.

## Этап B. Зрение и память о цели

- [x] **DINO-008** Реализовать `CreatureTargetMemory`: текущая цель, последняя известная позиция, время последнего обнаружения, сброс памяти. Не принимать решения о переходах состояний. — Выполнено: класс-хранилище `CreatureTargetMemory` (наблюдение, обновление позиции, `Clear`, срок `MemoryDuration`); подключён в `CreatureContext`/`CreatureController`, состояния не изменены.
- [x] **DINO-009** Реализовать проверку зрения: дистанция, угол обзора, raycast видимости и LayerMask препятствий. Использовать только игрока как цель первой версии. — Выполнено: `CreatureVision` (дистанция, полный угол обзора, raycast по `ObstacleLayerMask` до коллайдера цели); подключён через `CreatureContext.Vision`; `Target` и `EyePoint` — поля `CreatureController` (явная цель или автопоиск на слое `Player`).
- [x] **DINO-010** Добавить периодический тик восприятия с настраиваемым интервалом; не выполнять полный набор Physics-проверок каждый кадр. — Выполнено: `CreaturePerception` (интервал `CreatureConfig.PerceptionInterval`), тикается из `CreatureController.Update`, доступен через `CreatureContext.Perception`; память не меняет.
- [x] **DINO-011** Подключить обнаружение игрока к памяти цели и переключению Idle/Investigate/Chase. Если текущая FSM ещё не готова, сначала создать только выдачу результата perception без обходного дублирования логики. — Выполнено: `CreatureController.Update` тикает зрение и память, `CreatureStateMachine.ApplyPerception` — единственная точка переходов (вижу → `Chase`, не вижу но помню → `Investigate`, память истекла → `Idle`); новые состояния `InvestigateState`/`ChaseState` в базовом виде (уточнение погони — DINO-012, осмотра — DINO-013).
- [x] **DINO-012** Реализовать `Chase`: обновлять destination с ограниченной частотой, прекращать погоню при потере цели согласно таймеру памяти, не дёргать destination каждый кадр без необходимости. — Выполнено: путь перестраивается только при видимой цели и её смещении > `MinRepathDistance`, не чаще `DestinationUpdateInterval`; в упор destination ставится на агента; при потере цели/памяти маршрут снимается; при непостроенном пути — `CreatureStateMachine.RequestInvestigate()`; `Observe` только по реально видимой цели.
- [x] **DINO-013** Реализовать `Investigate`: двигаться к позиции, где игрок был замечен/услышан; завершать состояние по достижении точки или истечении таймера. — Выполнено: `InvestigateState` идёт к `Memory.LastKnownPosition` на `MoveSpeed`, перестраивает путь только при сдвиге точки больше `MinRepathDistance`; завершается по прибытии, по `CreatureConfig.InvestigateDuration` (временное, 8 с) или при непостроенном/потерянном пути; `NotifyInvestigationFinished()` не даёт повторно осматривать ту же точку, пока цель не появится снова.
- [ ] **DINO-014** Реализовать `Search`: ограниченный по времени поиск вокруг последней известной позиции. Не реализовывать сложную тактику обхода укрытий.
- [ ] **DINO-015** Реализовать `Return`: после неудачного поиска вернуться к исходной точке и перейти в Idle.
