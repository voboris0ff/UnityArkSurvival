- [x] **DINO-015** Реализовать `Search`: после завершения Investigate существо ограниченное время (`CreatureConfig.SearchDuration`) обходит случайные достижимые точки в `SearchRadius` вокруг `Memory.LastKnownPosition` с короткими остановками; при повторном обнаружении игрока переход в Chase только через `ApplyPerception`. Согласовать с `NotifyInvestigationFinished()` из DINO-013 (Investigate → Search, а не сразу Idle). Не реализовывать сложную тактику обхода укрытий. — Выполнено: `SearchState` (опора поиска — `LastKnownPosition` на входе, случайные точки `SearchRadius` через `Random.insideUnitCircle`, проверка близости `MinPointDistance`, `CanReach` + `TrySetDestination` с привязкой к NavMesh, до 8 попыток, пауза `SearchStopDuration` на точке, лимит `SearchDuration`); `InvestigateState.Finish` теперь ведёт в `Search`, добавлен `NotifySearchFinished()`; по окончании — Idle (смена дома и сброс памяти — DINO-016).

- [x] **DINO-023** Согласовать и реализовать правила приоритета зрительного обнаружения и слухового события, включая поведение при уже активных Chase, Search и Patrol. — Выполнено: правила зафиксированы в `docs/project-context.md` («Приоритеты зрения и слуха») и реализованы в `CreatureStateMachine.ApplyNoise`: (1) видимая цель всегда важнее шума — шум только логируется; (2) `Chase` шумом не прерывается; (3) `Return` шумом не отменяется; (4) `Search` продолжается, если шум попал в область поиска (`SearchRadius` вокруг `SearchState.Anchor`), иначе переключается на осмотр точки шума; (5) `Patrol`/`Idle`/`Investigate` — шум запускает (или перезапускает) `Investigate` к точке; шум рядом с уже осматриваемой точкой (< 3 м, временное `NoiseRetargetDistance`) только обновляет память. `SearchState.Anchor` открыт для чтения. `ApplyPerception` по-прежнему выполняется до `ApplyNoise`.
