- Время: 2026-11-04
- Результат: DINO-011 выполнена (`[x]`) — зрение → память → Idle/Investigate/Chase.

## Изменено
- `CreatureTargetMemory`: добавлен `Tick(dt)` (давность = накопленное время, убрана зависимость `HasTarget` от `Time.time`), `Observe` обнуляет давность.
- `CreatureStateMachine`: `ApplyPerception()` — единственная точка переходов по `Perception.TargetVisible`/`Memory.HasTarget`; в статике лог каждого перехода состояния.
- Новые `CreatureStates/InvestigateState.cs` (один путь к `LastKnownPosition`, завершение по прибытии/потере пути) и `ChaseState.cs` (`ChaseSpeed`, destination раз в `DestinationUpdateInterval`, `Observe` при назначении пути).
- `CreatureContext`: добавлен `Config`. `CreatureController.Update`: `Perception.Tick` → `Memory.Tick` → лог изменений → `ApplyPerception` → `StateMachine.Tick`; логи старта, видимости и памяти.
- Документы: `roadmap.md` (DINO-011 → `[x]`), `progress.md`, `project-context.md` (имена `Tick`, `ApplyPerception`), `manual-queue.md` (пункт DINO-011).
