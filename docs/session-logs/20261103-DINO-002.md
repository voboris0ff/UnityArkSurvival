# Сессия DINO-002

- Задача: DINO-002 — создать `CreatureConfig` ScriptableObject-класс с начальными параметрами навигации, восприятия, памяти и атаки.
- Результат: выполнено.

## Что сделано
- Прочитаны существующие конфиги `Assets/Scripts/Data/*.cs` и взят их стиль: `[CreateAssetMenu]`, `[Header]`, `[SerializeField] private`, публичные get-only свойства, `sealed`, namespace `ArkSurvival.Data`.
- Проверено поиском, что кода `Creature*` нет — конфликтов имён нет.
- Создан `Assets/Scripts/Data/CreatureConfig.cs` с четырьмя группами параметров:
  - `Navigation`: `MoveSpeed`, `ChaseSpeed`, `TurnSpeed`, `ArrivalDistance`, `DestinationUpdateInterval`;
  - `Perception`: `PerceptionInterval`, `SightDistance`, `SightAngle`, `EyeHeight`, `ObstacleLayerMask`, `HearingRange`;
  - `Memory`: `MemoryDuration`, `SearchDuration`;
  - `Attack`: `AttackRange`, `AttackAngle`, `AttackCooldown`, `AttackWindup`, `AttackDamage`.

## Решения/наблюдения
- Параметры включены с нейтральными стартовыми значениями; игровые числа не утверждались.
- `ObstacleLayerMask` по умолчанию `1` (только `Default`) как безопасная заглушка; реальная настройка — ручной шаг (manual-queue DINO-001 про слои).
- `SightAngle`/`AttackAngle` трактуются как полный угол конуса/сектора — это надо учесть при реализации проверок в DINO-009/DINO-022.
- `AttackDamage` — просто параметр, а не система урона. Контракт урона остаётся нерешённым (DINO-021).
- `.asset` и `.meta` не создавались: ассет создаст пользователь в Editor.
