# Сессия: корневая причина возврата найдена (DINO-006)

- Время: 2026-11-04T00:05
- Результат: DONE (нужна проверка в Play Mode)

## Лог пользователя
`status=PathComplete, pathPending=True, hasPath=False, isOnNavMesh=True, remaining=0,00,
destination=(0.00, 0.17, 10.00), position=(-7.25, 0.17, 0.00), corners=1`

## Корневая причина
- `IsPathActive` проверял `hasPath` **до** `pathPending`. Пока навигация считает путь, `hasPath` равен `false`, поэтому метод возвращал `false` на первом же тике.
- `ReturnState.Tick` видел «путь пропал» и уходил в `Idle`, а `IdleState.Enter` вызывал `Stop()` → `ResetPath()`. Путь уничтожался до старта движения.
- NavMesh в порядке: `isOnNavMesh=True`, `PathComplete`, corners=1, дистанция ~11 м по оси Z — путь корректный.

## Изменено
- `CreatureNavigator.IsPathActive` — порядок: `IsReady`/`isStopped` → `pathPending` → `hasPath`/`PathInvalid` → `PathComplete` → `remainingDistance`.
- `TrySetDestination` — комментарий, поясняющий, почему проверка `PathPartial` не может выполниться при `pathPending` (её закрывает `IsPathActive`).
- `ReturnState.Tick` — диагностический лог состояния агента оставлен.
- `docs/manual-queue.md` — DINO-006 переписан под обычную проверку.
