# Очередь ручных действий

### DINO-064 — проверить переходы слоя переноски в PlayMode
- **Что сделать:** Соберите слой `Carry Upper Body` по DINO-059 (если ещё не собрали), войдите в PlayMode и проверьте по списку:
  1. Стойка с поленьями: поза «на плече» есть, ноги стоят/идут в базовой анимации.
  2. Ходьба с поленьями: поза сохраняется, ноги не ломаются, спринт недоступен.
  3. Кувырок с поленьями: клип кувырка играет целиком, поза «на плече» не примешивается; поленья сбрасываются (DINO-061).
  4. Прыжок с поленьями: клип прыжка играет целиком, поза «на плече» не примешивается; поленья сбрасываются (DINO-062).
  5. После сброса поленьев вес слоя плавно уходит в 0 за ~0.2 с, руки опускаются без рывка.
  6. При взятии поленьев вес слоя плавно приходит, без рывка.
- **Где:** PlayMode в Unity, префаб игрока → Animator (`Player.controller`), слой `Carry Upper Body`.
- **Зачем:** смешение позы переноски с кувырком и прыжком ломает силуэт и читаемость этих движений; вес слоя должен уходить в 0, а не выключаться мгновенно.
- **Готово, когда:** Все пункты списка выполняются; в консоли нет предупреждений про отсутствующий слой/маску/параметр.

### DINO-059 — слой переноски поленьев: маска, поза, переходы
- **Что сделать:**
  1. Создайте `AvatarMask` `CarryUpperBody.mask` (`Assets → Create → Avatar Mask`): включите кости корпуса/плеч/рук/кистей, кости ног и таза выключите. Источник — `Avatar` модели персонажа.
  2. Сделайте клипы позы «поленья лежат на плече, рука их придерживает»: `Carry Idle` (стоя) и `Carry Walk` (ходьба). Анимируйте только верхнюю часть тела; ноги не трогайте — их играет базовый слой.
  3. В `Player.controller` создайте слой `Carry Upper Body` поверх `Base Layer`: Weight = `1`, Blending = `Override`, Mask = `CarryUpperBody.mask`.
  4. В слое: состояние `Empty` (пустой клип) — по умолчанию; состояние `Carry Locomotion` с 1D Blend Tree по параметру `Speed` (`Carry Idle` на 0, `Carry Walk` на скорости ходьбы).
  5. Переходы `Empty → Carry Locomotion` при `IsCarrying = true` и обратный при `IsCarrying = false`: `Has Exit Time` выкл., Transition Duration ≈ `0.2`. Плавность веса слоя даёт именно длительность перехода, вес слоя руками не меняйте.
- **Где:** `Assets/Art/Characters/Player.controller`, Animator → Layers / Parameters; ассеты маски и клипов — рядом с моделью.
- **Зачем:** `PlayerAnimator.SetCarrying` уже публикует `IsCarrying` (DINO-058). Без слоя и позы поленья висят на `CarryAnchor` при обычной анимации тела.
- **Готово, когда:** Параметр `IsCarrying` есть в контроллере (см. DINO-058); при переноске рука поднята к плечу и поленья лежат на плече в стойке и в ходьбе; после разгрузки руки плавно опускаются за ~0.2 с; ноги, кувырок и прыжок не затрагиваются.
