# Очередь ручных действий

Канал связи с пользователем. Только незакрытые пункты: выполненные агент удаляет сам после разбора `Ответ пользователя:` (см. `AGENTS.md`, раздел «Общение с пользователем»). После получения ответа от пользователя, агент проверяет задачу, если пользователь подтвердил её выполнение агент должен удлалить эту задачу

## Соглашения, принятые из ответов
- Слои: `3 — Creature`, `6 — Player`, `7 — Obstacle` (имя из `TagManager.asset`); для raycast зрения используется слой Obstacle.
- `Assets/Configs/CreatureConfig.asset` создан, NavMesh запечён, `CreatureController` и `NavMeshAgent` настроены.
- Возврат к домашней точке (DINO-006) работает.
- DINO-007 закрыта: клипы `walk`/`run` у Raptor есть.
- DINO-009: `Player` на слое Player с коллайдером; в `CreatureController` назначен `Eye Point`. Слой Obstacle использован в маске препятствий зрения.
- DINO-017: блок `Patrol` в `CreatureConfig.asset` проверен пользователем и подтверждён.
