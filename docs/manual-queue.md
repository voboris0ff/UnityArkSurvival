# Очередь ручных действий

Канал связи с пользователем. Только незакрытые пункты: выполненные агент удаляет сам после разбора `Ответ пользователя:` (см. `AGENTS.md`, раздел «Общение с пользователем»).

## Соглашения, принятые из ответов
- Слои: `3 — Creature`, `6 — Player`, `7 — obstacle` (для raycast зрения).
- `Assets/Configs/CreatureConfig.asset` создан, NavMesh запечён, `CreatureController` и `NavMeshAgent` настроены.
- Возврат к домашней точке (DINO-006) работает.
