# Очередь ручных действий

Канал связи с пользователем. Только незакрытые пункты: выполненные агент удаляет сам после разбора `Ответ пользователя:` (см. `AGENTS.md`, раздел «Общение с пользователем»). После получения ответа от пользователя, агент проверяет задачу, если пользователь подтвердил её выполнение агент должен удлалить эту задачу

## Соглашения, принятые из ответов
- Слои: `3 — Creature`, `6 — Player`, `7 — Obstacle` (имя из `TagManager.asset`); для raycast зрения используется слой Obstacle.
- `Assets/Configs/CreatureConfig.asset` создан, NavMesh запечён, `CreatureController` и `NavMeshAgent` настроены.
- Возврат к домашней точке (DINO-006) работает.
- DINO-007 закрыта: клипы `walk`/`run` у Raptor есть.
- DINO-009: `Player` на слое Player с коллайдером; в `CreatureController` назначен `Eye Point`. Слой Obstacle использован в маске препятствий зрения.
- DINO-017: блок `Patrol` в `CreatureConfig.asset` проверен пользователем и подтверждён.

### DINO-023 — проверить приоритеты зрения и слуха в Play Mode
- **Что сделать:**
  1. Оставить на объекте сцены `CreatureNoiseDebugInput` (клавиша `N`) и компонент `PlayerNoiseEmitter` на игроке.
  2. Запустить Play Mode и дождаться, пока существо патрулирует. Нажать `N` в пределах слуха — существо должно перейти в `Investigate` к точке шума.
  3. Дать существу увидеть игрока (началась `Chase`) и нажать `N`: в Console должно быть «но цель видна — шум не меняет поведение», погоня продолжается.
  4. Дождаться `Search` (потеря цели) и нажать `N` рядом с областью поиска (в пределах 8 м от места, где цель пропала): должно быть «внутри области поиска, поиск продолжается». Нажать `N` далеко (дальше 8 м, но в пределах слуха) — должен начаться осмотр новой точки.
  5. Нажать `N` во время осмотра рядом с осматриваемой точкой (до 3 м) — осмотр не перезапускается; дальше — перезапускается к новой точке.
  6. Нажать `R` (возврат) и `N` — возврат не должен прерываться.
- **Где:** сцена `Assets/Scenes/SampleScene`; значения — `Hearing Range`/`Search Radius` в `Assets/Configs/CreatureConfig.asset`.
- **Зачем:** DINO-023 зафиксировал приоритеты зрения и слуха для Chase/Search/Patrol/Return; нужна проверка полной цепочки на сцене.
- **Готово, когда:** поведение совпадает с пунктами 2–6, в Console есть соответствующие строки.

### DINO-020 — проверить слух в Play Mode
- **Что сделать:**
  1. Добавить на любой объект сцены (например, на игрока или пустой объект) компонент `CreatureNoiseDebugInput` (`Assets/Scripts/AI/Creatures/CreatureNoiseDebugInput.cs`).

  3. Нажимать `N` и смотреть Console: должно появляться «CreatureController: услышал шум от …» только когда дистанция до источника ≤ `HearingRange * Loudness` (по умолчанию `HearingRange = 12`, `Loudness = 1` → до 12 м).
  4. Уменьшить `_loudness` в компоненте (например, 0.5) — слышимость должна сократиться примерно вдвое.
- **Где:** сцена `Assets/Scenes/SampleScene`, компонент `CreatureNoiseDebugInput`; значения слуха — `Assets/Configs/CreatureConfig.asset`, поле `Hearing Range`.
- **Зачем:** DINO-020 добавил приём шума, но игрок пока не издаёт шум сам (DINO-022), поэтому нужен временный ручной издатель.
- **Готово, когда:** шум слышен в пределах `HearingRange * Loudness`, не слышен за пределами; в Console есть строка о услышанном шуме с дистанцией и дальностью.
