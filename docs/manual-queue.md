### DINO-029 — настроить анимацию атаки в `Raptor.controller`
- **Что сделать:**
  1. В `Raptor.controller` добавить параметр `Attack` типа **Trigger** (имя именно `Attack`).
  2. Добавить стейт с клипом атаки Raptor и переход в него по триггеру `Attack` из `idle`/`walk`/`run`; обратный переход — по окончании клипа (без `Has Exit Time` из стейта атаки в движение).
  3. На кадре удара клипа атаки добавить **Animation Event** с функцией **`OnAttackHit`** (без аргументов).
  4. На GameObject с Animator (обычно модель Raptor) добавить компонент `CreatureAttackAnimationEvent`.
  5. Проверить в Play Mode: при замахе играет клип атаки; лог `CreatureAttack: удар попал/промахнулся` появляется в кадре события, а не по таймеру.

- **Готово, когда:** замах существа сопровождается клипом атаки, Animation Event `OnAttackHit` совпадает с визуальным ударом, предупреждение `CreatureAnimator` о параметре `Attack` в Console отсутствует.
