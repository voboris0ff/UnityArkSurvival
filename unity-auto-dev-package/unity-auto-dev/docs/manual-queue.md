# Очередь ручных действий

Здесь находятся только действия, которые пользователь должен выполнить в Unity Editor или решения, которые нельзя безопасно принять за него.

## Ожидает выполнения

Пока нет подтверждённых ручных действий по существу. По мере выполнения задач агент должен добавлять сюда конкретные пункты.

## Правила ведения очереди
- Не добавлять сюда действия, которые агент может выполнить обычным изменением C# или Markdown.
- Каждый пункт должен содержать: что сделать, где сделать, зачем и как понять, что готово.
- После выполнения пользователь отмечает пункт `[x]` или сообщает агенту, что он выполнен.
- Если ручное действие блокирует дальнейшую разработку, явно указать блокирующие задачи.
- Не удалять выполненные пункты: переносить их в раздел «Выполнено» для сохранения истории.
